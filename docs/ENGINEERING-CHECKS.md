# VoltGrid — інженерні перевірки (етап 2): перелік формул і джерел

Статус: **чернетка для погодження**. Ніякі числа тут не потрапляють у код, доки не позначені як «звірено з першоджерелом». Усі значення зберігаються в регіональному профілі, а не в коді.

Позначки: ✅ — підтверджено в знайденому джерелі; ⚠️ — потребує звірки з чинним виданням норми; ❌ — джерела ще немає.

## 1. Захист від перевантаження (PN-HD 60364-4-43)

- ✅ Умова 1: `Ib ≤ In ≤ Iz` (розрахунковий струм кола, номінальний струм захисту, тривало допустимий струм кабелю).
- ✅ Умова 2: `I2 ≤ 1,45 · Iz`, де `I2 = k2 · In`; для автоматів B, C, D `k2 = 1,45`, для запобіжників 1,6–2,1.
- Джерело: [SEP — Ochrona przed prądem przetężeniowym w instalacjach nn](https://sep.com.pl/opracowania/opracowania_ochrona_przed_pradem_przetezeniowym_w_instal_elekt_nn.pdf).

## 2. Захист від короткого замикання (PN-HD 60364-4-43 / -5-54)

- ✅ Час нагріву жили: `t = (k · S / I)²` для часу до 5 с; для часу менше 0,1 с — `k²S² > I²t` (енергія пропуску апарата від виробника).
- ⚠️ Коефіцієнти `k` для Cu: у джерелі значення для PVC 70 °C = 115, PVC 90 °C = 100, XLPE = 143, але таблицю текстом розсипано. **Звірити з HD 60364-5-54, додаток A, перш ніж використовувати.**
- Для цієї перевірки потрібна `Ik max` у точці встановлення апарата й дані про `I²t` або відключну здатність апарата — тобто потрібні параметри мережі живлення (див. питання нижче).

## 3. Автоматичне відключення живлення (PN-HD 60364-4-41)

- ✅ Максимальний час відключення кінцевих кіл, таблиця 41.1: TN — 0,4 с для 230 В; TT — 0,2 с для 230 В (120 В: 0,8 / 0,3 с; 400 В: 0,2 / 0,07 с). Джерело: [VIOX — Why 0.4 seconds](https://viox.com/pl/why-0-4-seconds-maximum-disconnection-times/) (посилається на IEC 60364-4-41, не на PN-HD; значення для PN-HD потрібно підтвердити).
- ⚠️ Умова `Zs · Ia ≤ U0`, де `Ia` — струм, що гарантує спрацювання за потрібний час. Формулу вважаємо стандартною, але у знайдених джерелах її не було; звірити.
- ❌ Типові значення `Ia` для MCB B/C (кратність 5·In і 10·In — стандартні для IEC 60898-1, але мають бути підтверджені документом виробника або нормою).
- Для розрахунку `Zs` потрібні опір кабелю (з довжини лінії — це вже є в `core`) та імпеданс джерела до щита `Zs_source` (вводить користувач).

## 4. Диференціальний захист RCD 30 мА

- ✅ Ванні та душові: усі кола у приміщенні з ванною/душем — RCD 30 мА (PN-HD 60364-7-701:2010); винятки — електричне розділення та SELV/PELV.
- ⚠️ Розеткові кола: у розглянутій статті (за PN-HD 60364-4-41:2009) — розеткові кола до 20 А для неосвічених користувачів; межа 32 А стосується мобільного обладнання на відкритому повітрі. **Чинне видання може вимагати інше (є редакція 2017 року) — звірити, перш ніж писати правило.**
- ⚠️ Освітлення, кабелі в стінах: у знайденому джерелі не розглядається.
- Рекомендований тип (A/AC/F/B), селективність (S-тип): ❌ джерела ще немає.

## 5. Тривало допустимий струм `Iz` (PN-HD 60364-5-52, табл. B.52.x)

- ❌ Таблиці `Iz` за способами прокладання (A1, B1, C та ін.) — у платній частині стандарту; у вільному доступі я підтверджених значень не знайшов.
- ❌ Поправочні коефіцієнти: температура середовища, групування кабелів, прокладання в теплоізоляції.
- Варіанти джерела: (a) ви надаєте таблиці з норми, (b) беремо таблиці виробника кабелю (наприклад, каталог NKT/Telefonika/Elpar) з прив'язкою до способу прокладання, (c) відкладаємо цю перевірку, поки не буде підтвердженого джерела.

## 6. Падіння напруги `ΔU`

- ✅ Формули для моно- та трифазного кола (з довжини, струму, питомого опору та cosφ) — математично стандартні й однозначні.
- ❌ Допустимі межі (наприклад, 3 % для освітлення, 5 % для інших споживачів — значення типові, але у знайденому матеріалі не підтверджені). Нормативне посилання — PN-HD 60364-5-52, додаток G; перед записом у профіль треба підтвердити.
- ✅ Довжина кабелю береться з `core` (вже реалізовано) — це головний вхід розрахунку. Для електричного розрахунку береться чиста траса (`baseMm`), без запасу на закупівлю.
- **Реалізовано** у `packages/core/src/checks/voltageDrop.ts`. Питомий опір міді в профілі PL (`0,0206 Ом·мм²/м` при 70 °C) — це **моє обчислення**, а не значення з норми: ρ20 = 0,017241 Ом·мм²/м, температурний коефіцієнт 0,00393 1/°C → 0,017241 · (1 + 0,00393 · 50) ≈ 0,0206. Потребує звірки з нормою/документом виробника. Реактивним опором кабелю нехтуємо (перерізи ≤ 16 мм²).
- Межі `limitsPercent` у профілі **не задані**: перевірка повертає статус «межу не задано», доки значення не звірено.

## 7. Баланс фаз (3-фазна мережа)

- Алгоритм розподілу кіл по L1/L2/L3 за потужністю — наша логіка, без нормативних чисел; допустима нерівномірність — налаштовується користувачем.

## 8. Параметри мережі, які потрібно вводити користувачу

Тип системи заземлення (TN-S / TN-C-S / TT), напруга (230/400 В), імпеданс джерела або струм КЗ на вводі, максимальна потужність, тип і марка апаратів (щоб брати `I²t` і криві з документів виробника).

## 9. Застереження

Програма — допоміжний інструмент. Результати перевірок мають статус «попередження», а не «висновок»; проєкт підписує особа з відповідними повноваженнями.
