# VoltGrid — уточнене ТЗ (v0.2)

Програма для проєктування електромереж і розрахунку матеріалів у багатоповерхових новобудовах. Базовий регіон — Польща, архітектура з розширенням на інші країни.

## 1. Рішення за результатами уточнень

| Тема | Рішення |
|---|---|
| Використання | Власні об'єкти + розрахунок як послуга замовникам |
| Об'єкти | Багатоповерхові новобудови, вся будівля: квартири та загальні зони (ВРУ, стояки, сходові клітки) |
| Пріоритет | Технічна частина: кількості обладнання, траси, кабелі. Фінанси — другорядно |
| Підоснова | PDF (основний), скани/фото (калібрування масштабу обов'язкове) |
| Трасування | Автоматичне + ручне редагування |
| Перевірки | Повний набір: переріз, ΔU, Zs/Ik, MCB/RCD/RCBO, селективність, баланс фаз |
| Мережі | 1-фазна та 3-фазна |
| Зберігання | Локальні файли проєкту (JSON), без хмари |
| Платформа | Windows (ціль), тестування на Nobara / Linux Mint |
| Робота з репозиторієм | Гілка main, пуш лише з явного дозволу власника |

## 2. Виключено або відкладено

- **Прибрано:** DWG (залишаємо DXF у пізнішій фазі), окремий mobile-режим.
- **Відкладено:** 3D-візуалізація, хмарна синхронізація, інтеграція з прайсами (до уточнення форматів).

## 3. Технології

TypeScript, React, Vite, Konva (2D), pdf.js (імпорт PDF), Vitest (тести), pnpm-монорепо. Обгортка Tauri для Windows додається після стабільного веб-ядра.

Структура пакетів:

- `packages/core` — модель даних, трасування, розрахунки (без UI, повністю тестується)
- `packages/regions` — регіональні профілі (JSON + валідація схеми), стартовий профіль PL
- `packages/export` — XLSX / CSV / PDF
- `apps/web` — редактор

## 4. Принципи розрахунків

- Усі формули, коефіцієнти та норми живуть у регіональному профілі, а не в коді.
- Прозорість: для кожного підсумку доступна деталізація (чиста траса, опуски, обходи, запас, округлення до упаковки).
- Одиниці: цілі міліметри, ніяких дробів у моделі.
- Формула довжини лінії (прийнята поки що, за потреби виправимо): `L = (горизонталь + вертикальні опуски/підйоми + обходи) × (1 + K_запасу)`.
- Еталонні (golden) тести: набір вручну перевірених кошторисів і перевірок захисту.
- Застереження: програма — допоміжний інструмент і не замінює проєкт особи з відповідними повноваженнями.

## 5. Етапи

| Етап | Зміст | Результат |
|---|---|---|
| 0 | Каркас монорепо, README, формат проєкту, профіль PL (**виконано**) | Порожній, але працюючий скелет |
| 1 | `core`: модель (поверхи, групи, лінії), каталог кабелів у профілі PL, розрахунок довжин, бухти (глобально / по групах) (**виконано**; кімнати й точки додаються з редактором) | Тестований розрахунок без UI |
| 2 | Інженерні перевірки: допустимий струм, ΔU, Zs/Ik, підбір захисту, баланс фаз (**частково**: ΔU, баланс фаз, умови перевантаження — готово; Iz, Zs/Ik, RCD чекають на підтверджені джерела) | Звіт попереджень |
| 3 | Редактор: імпорт PDF/фото, калібрування, стіни та отвори, розміщення точок (**перша версія готова**: полотно, PDF/зображення-підкладка, масштаб 1:N та калібрування, стіни, двері/вікна, розетки/вимикачі/світильники, поверхи, undo/redo, збереження/відкриття файлу; перевірено на реальному плані 1:100) | Малювання плану |
| 4 | Автотрасування (ортогональне, обхід отворів) + ручне редагування (**перша версія готова**: щит, кола, побудова трас через двері з відступом 20 см, таблиця замовлення кабелю; ручне редагування: вибір лінії й перетягування ланок, обхід перераховується; варіанти розводки 1–3 — далі) | Траси на плані |
| 5 | Специфікація (BOM), двостороння підсвітка, експорт XLSX/CSV/PDF (**частково**: BOM кабелю, бухт, точок і кіл + експорт CSV; XLSX/PDF, рамки/коробки/Wago — після відповідей щодо методики) | MVP |
| 6 | Однолінійна схема щита, наклейки, кошторис робіт, прайси | Повний пакет документів |
